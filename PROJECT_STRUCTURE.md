# Camp Rishikesh - Responsive Full Project

## Project Overview
A complete responsive camping website built with React, featuring multiple pages and full mobile responsiveness.

## Pages Created
1. **Home** - Main landing page with carousel, booking form, and features
2. **About** - About the campground
3. **Campground** - Accommodation options and facilities
4. **Events** - Upcoming events with filtering
5. **Gallery** - Photo gallery with categories
6. **Near Me** - Nearby attractions and restaurants
7. **Contact** - Contact form, info, and FAQ

## Key Features
- ✅ Fully responsive design for all screen sizes
- ✅ Mobile-first approach
- ✅ Bootstrap 5 integration
- ✅ Material-UI components
- ✅ React Router navigation
- ✅ Redux state management
- ✅ Authentication system
- ✅ Interactive components
- ✅ Modern UI/UX design

## Responsive Breakpoints
- **Mobile**: < 576px
- **Tablet**: 576px - 768px
- **Desktop**: > 768px

## Technologies Used
- React 19.1.0
- Bootstrap 5.3.7
- Material-UI 7.2.0
- React Router DOM 7.7.0
- Redux Toolkit 2.8.2
- React Icons 5.5.0
